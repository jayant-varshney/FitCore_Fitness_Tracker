# FitCore Fitness Tracker

A full-stack fitness tracking web application designed to help users monitor workouts, diet plans, BMI, and overall fitness progress.

## Features
- Workout tracking
- BMI calculator
- Weekly fitness reports
- Progress dashboard
- Responsive user interface
- MySQL database integration

## Tech Stack
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## Project Structure
- `public/` → Frontend files
- `server.js` → Backend server
- `schema.sql` → Database schema
- `package.json` → Dependencies and project configuration

## Future Improvements
- User authentication
- AI-powered fitness recommendations
- Cloud deployment
- Advanced analytics dashboard
- Real-time notifications
